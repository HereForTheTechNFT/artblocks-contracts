# Art Blocks : architecture

L’architecture sépare les contrats de base, les modules spécialisés et les intégrations. Cette séparation rend les responsabilités lisibles : GenArt721, projects, scripts, randomizer, minters, auctions, royalties. Les paramètres critiques doivent toujours être vérifiés dans la version déployée.
